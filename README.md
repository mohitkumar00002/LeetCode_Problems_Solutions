Structured LeetCode Problem Solutions (Pattern Wise)

This repository contains my daily practice of LeetCode problems solved in a structured and pattern-based manner.

The purpose of this repository is to:
- Build strong DSA fundamentals
- Practice problem-solving patterns
- Maintain daily consistency
- Track my interview preparation journey

Why Pattern-Based Practice

Instead of solving random problems, I follow a pattern-first approach where similar problems are grouped together.  
This helps in better logic understanding and faster problem solving.

Patterns Covered

- Array and String
- Two Pointer
- Sliding Window
- HashMap and HashSet
- Prefix Sum
- Stack and Queue
- Linked List
- Recursion and Backtracking
- Trees
- Graphs
- Heap and Priority Queue
- Greedy
- Dynamic Programming

Daily Practice Rule

- Problems are solved pattern-wise
- Clean and readable code is written
- Solutions are pushed daily to GitHub
- Focus is on logic, not memorization

Problem Format

Each solution includes:
- LeetCode problem number and title
- Pattern used
- Java implementation

Language Used : Java
